## 一、文件和入口

- 文件 `梦与非梦_第二部.html`，跟第一部放在同一个目录。
- 第一部结局页上，台上的世界线（W、R、C、G2）多一个按钮“进入第二部”，链接是 `梦与非梦_第二部.html#MFM2-…`。
- 第二部开始页可以粘贴代码。地址里带了代码就自动填上。MFM1 的 W 代码也认。
- 第一部最后几场的选择（W 局的 w1、w2，R 局的 r1、r2，C 局的 c1、c2，上海那一周的 e6）不全在代码里，入口按钮用 `&x=r1_deng.r2_mid` 这样带过去。W 局的子型按位记了 w1、w2 和 ec_purge，第二部会还原。只粘贴代码的，R、C 局缺这几项，就当没选。不在台上的代码，显示这一局留下了什么，说明没有第二部。
- 开始页另有四个“示例开局”，不用玩第一部也能进。

九个派系：理论派、造反派干部、华国锋那边、老干部、军队、工人、农民、知识分子和技术员、地方。

### 开局态度

按第一部的关系和个人四项推出（`世界线代码说明.md` 第六节）。理论派看张春桥，造反派干部看上海造反派，华国锋那边看华国锋，老干部看老干部，工人看清白和几条事实，知识分子看推荐考试、技术员这几条。

### 投票

一张卡上大多数选项要过会。你提一个方案，各派按这一张卡上写的赞成或反对；卡上没写的派，按对你的态度跟着走（赞成以上跟你，不满以下反对你，观望不投）。每派有一个分量，你自己也有一个分量。

| 派系 | W | R | C | G |
|---|---|---|---|---|
| 你 | 3 | 1 | 2 | 1 |
| 理论派 | 3 | 0 | 2 | 0 |
| 造反派干部 | 3 | 1 | 2 | 1 |
| 华国锋那边 | 1 | 3 | 2 | 2 |
| 老干部 | 1 | 3 | 2 | 3 |
| 军队 | 2 | 2 | 2 | 2 |
| 工人 | 2 | 1 | 1 | 1 |
| 农民 | 1 | 1 | 1 | 1 |
| 知识分子和技术员 | 0 | 1 | 1 | 1 |
| 地方 | 2 | 2 | 2 | 2 |

W 局里华国锋被抓了，华国锋那边的分量降到 0。G 局里，卡上标了“劳动”的，你的分量加 1（全总说话）。

赞成的分量加你自己的分量，大于反对的分量，就通过。没通过，会上通过的是另一个方案，看卡上写的 `fb`，没写就取各派净支持最高的那一个。投票的结果在选完以后的页面上写出来，谁赞成，谁反对。

有的选项不过会（`vote:false`），是你自己的事，选了就做。

维度“农村集体”越高越接近包产到户（跟世界线代码说明 5.2 的档位一致），“计划与价格”越高价格放得越开。

### 指标怎么算

每年按增长率滚一遍（1978 年只剩十二月，不滚）。增长率等于世界的基数，加上维度的修正，加上这些年选过的卡的修正（卡的修正一直有效）。1979 年以后的数字都标“推演”，旁边写历史上这一年的数字（`HIST2`，国家统计局年鉴等，住房有五年、人均粮食有六年是插值）。

年终还会按数字动两派。工资扣掉物价几乎没涨，工人冷一档；涨得快，热一档；物价一年涨八以上，工人再冷一档。农民收入扣掉物价涨六以上，农民热一档，不到二，冷一档。城镇待业超过七百万，造反派干部冷一档。

## 三、卡

```js
{ id:"zq79", y:1979, n:"知青", w:["W","R","C","G"], when:"表达式", labor:true,
  place:"北京 · 国务院知青办",
  text: 文字,             // 文字可以是字符串、{W:…, R:…, _:…}、或 [[条件, 字符串], …]
  ref: "历史上……",       // 参照，收起显示
  fb: {W:2, _:1},        // 你的方案没通过时，会上通过哪一个（可省）
  c: [ { t:"选项", mean:"这一项意味着什么", w:["W"], req:"条件", lock:"锁住时说明",
         vote:true, pro:["gong"], con:["lao"],
         eff:{ d:{"福利范围":1}, f:{gong:1}, i:{wage:2}, x:{su:-1}, set:["zq_all"], pos:-1 },
         gb:"公报里的一句", nc:"内参里的一句", res:文字 } ] }
```

派系键：li 理论派、zf 造反派干部、hua 华国锋那边、lao 老干部、jun 军队、gong 工人、nong 农民、zhi 知识分子和技术员、di 地方。外部键：us 美国、jp 日本、su 苏联、tw 第三世界。

指标修正 `i`：wage、farm、house、price 是每年增长率加减的百分点；debt 是每年多借的亿美元；jobless 是这一年待业人数加减的万人。

条件表达式里能用：`W R C G`（布尔）、`has("标记")`（第二部标记和第一部事实键都算）、`d("维度名")`、`f("gong")`、`pos`、`y`、`ppl("覃月梅")`、`stage("邓小平")`、`ax("voice")`。

## 五、结局

1989 年那一张卡选完以后，按状态挑一个结局。位置到 0 就提前结束，叫“靠边”，每一种世界写法不同。每一个结局有总结、来龙去脉（收起）、这十年的数字和历史上的对照。

结局在 `ENDINGS2` 里按顺序判断，第一个条件成立的就是。名字沿用 IF 线第三版的四个（大退却、停滞、自己人、罢工自由），再加各局自己的。现在一共十二个：罢工自由、自己人、工会是谁的（G）、顾问（R）、大退却（W、C）、中间（C）、停滞、没有举手，加四种靠边。

## 六、文件怎么改

卡、词条、结局都在 `梦与非梦_第二部.html` 第一个 `<script>` 里，`CARDS2.push(…)`、`Object.assign(GLOSS2, …)`、`ENDINGS2.push(…)`，后面一段“补丁”是审读以后改的顺序、条件和几段文字。引擎在第二个 `<script>`。测试 `tests/part2.js`（四种示例开局随机走，查报错、空文字、结局分布、1989 年的数字）、`tests/part2link.js`（第一部结局页的入口）。

## 七、写法

跟第一部一样。不用破折号，不用冒号引出一串列举，不用“不是X而是Y”“而非”“与其说”，不用感叹号。直白朴素。参照里的史实写“历史上”，书只能转述。1979 年以后的事是推演，正文里写的事件如果在历史上发生过，参照里说清楚历史上是怎样的。
