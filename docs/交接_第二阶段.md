## 一、Skill 要求（摘要）

完整版见 `.claude/skills/meng-yu-feimeng/SKILL.md`。最要紧的几条：

- **写作**。不用破折号；不用冒号引出列举；不用“不是 X 而是 Y”“与其说……不如说”“而非”；第二人称克制；先铺情境再给选择；情绪靠细节；受害者要在场。
- **史料**。每条注都标史实、有争议或虚构，写出处。背景面板里的作者观点标“解释”。
- **版权**。受版权保护的书一个字都不进仓库，只转述并注明“（转述）”和章号。`sources/` 只放公开文本。
- **分支**。只在 `act2-draft` 上做，阶段性提交推送，不碰 main，不开 PR。
- **待决定的事**写进 `docs/待确认.md`，带默认值，然后按默认继续。
- **改完必测**。语法快检和 `tests/` 里的 Playwright 脚本，手机宽度、浅深两种主题，零报错、零横向溢出。

方法上的几点：

- **读书**。epub 解开后切成四十多段，在临时目录逐段读，读完一段就把和王洪文、和游戏现有场景、和 IF 线有关的东西记成笔记（只在临时目录）。改游戏时回原文核对一遍原话再转述。
- **史实冲突**。两种来源说法不一，就两说并存，在史料注里写清各自依据，游戏取一种并说明为什么；正文尽量写成两种说法都不矛盾的样子，或者让两个选项分别对应两种说法。
- **IF 线**。每条梦里的路都有一个具体选择做种子，再靠四项分量累积开门；开门的选项标“梦里多出来的一条路”。路走出去以后，后文所有地方都要按这条路改写，用测试脚本把每条路走到尾声检查。
- **数值**。改了前面的选项或分量，就用 `presetvals.js` 和 `policy.js` 看五种人和几种固定策略走到各幕时的分量，确保不会全部卡在一条路上。

## 三、成品

### 游戏

`梦与非梦.html`，单文件，浏览器直接打开。

- 六幕加尾声，从 1966 年 6 月国棉十七厂的广播到 1992 年秦城，尾声是今天网上的“小王同志”。约 120 个场景。
- 每一步有直接后果、历史上的选择、档案的 1967 年写法和 1977 年写法。
- 四项分量 放手、留情、不沾、向上靠，可以点开看解释。
- 16 处“梦里多出来的一条路”，第三到第六幕有 IF 线（巴黎公社、两派一起管厂、登记制、和天安门的人站在一起、与邓小平合作、民兵、改期等）和五条跨幕支线（k1、k2、k3、k4、k6）。
- 23 种结局、16 种改变、7 种组合，标题页“结局与成就”可查；梦满三次以后显示各条路要攒够什么。
- 从第二到第六幕任选一幕开始，五种人可选，选之前看得到分量预览。每一幕可以保留原来的重做、换一种人重做或从头。
- 背景面板（历史情景和解释）、人物卡、术语链接、史料注（史实、有争议、虚构）。
- 手机宽度可玩，浅色深色两套主题。
