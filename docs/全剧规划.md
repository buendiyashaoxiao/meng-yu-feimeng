## 二、IF 线怎么跨幕延续

- 每条 IF 线一旦长出来，就在后面每一幕都有自己的场景，和历史线并行，不再回到历史线。
- 每条 IF 线到第六幕都要收束，回答讨论记录里的三个问题。这件事为什么历史上没发生？谁付了代价？能维持多久？
- IF 线越往后越长。A1 巴黎公社线如果一直走下去，第三到第五幕的场景基本都是另写的，最后在第六幕以不同的身份见到秦城，或者见不到秦城。

| IF 线 | 第三幕 | 第四幕 | 第五幕 | 第六幕 |
|---|---|---|---|---|
| A1 巴黎公社 | 1967 年选举、军管危机、分出三种走向 | 选举制地方政权与中央的拉锯 | 1976 年选出来的人怎么站队 | 秦城，或者八十年代一个区里的选举 |
| A2 结社自由 | 登记制度、上柴联司也登记了 | 四大入宪（A4） | 四五时的组织 | 审判时“结社”成为罪名还是辩护 |
| A7 两派和解 | 联司那一夜 | 老陆当了车间主任 | 1976 年两派老工人的态度 | 老陆来秦城探监，或者没来 |

## 七、全剧完成后要回头做的事

1. IF 线目前在各幕内收尾，可以再拆开，跨幕延长。
2. 第三到六幕的史料主要来自黄金海回忆录和维基，徐景贤《十年一梦》、李逊《革命造反年代》、叶永烈《王洪文传》都还没有读到原文，需要逐条核对。
3. 第三幕以后视觉偏少，可以补报纸头版、判决书、探视证等物件。
4. 三种讲法在第四幕以后写得比较短，可以加长。
