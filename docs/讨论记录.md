# 讨论记录

## 2026 年 9 月 30 日

这一轮在交接说明和第一幕 demo 的基础上，讨论了后续方向。下面是已经定下来的决定，后续工作以这里为准。凡是和交接说明冲突的地方，以这份记录为准。

### 一、IF 线怎么触发

- **一局之内就能走进 IF 线。** 不强迫玩家反复重玩同一幕来解锁。IF 线的入口由同一局里前面几个选择决定，走到某个节点时自然多出一个原本没有的选项。
- 交接说明第三节第 3 条“IF 线是走着走着长出来的”仍然成立，但“长出来”指的是一局之内的积累，不是多周目的积累。
- 秦城之梦的框架和“第 N 次梦见安亭”保留，但重玩只是可选的，不是解锁条件。

### 二、死局

- **每一幕里都要有直接走死的可能。** 包括肉体上的死和政治上的死（被隔离审查、被开除、被遗忘），也包括道德上的死局（签了字，档案里永远留下一笔）。
- 死局之后照样醒在秦城，告诉玩家这一局在档案里留下了什么。
- 草案见 `IF线与视觉设计.md` 第三节。

### 三、历史的惯性

- 同意“历史有惯性”。大事件照常发生，偏离主要体现在王洪文的位置和别人怎么记他。
- 但下面这些重大转折**必须能真的发生**，而且不止这几条，要多开脑洞。
  - 江青成功
  - 与邓小平合作
  - 巴黎公社原则真正实施
  - 某种辅佐让改革开放变得更好
  - 更早接触美国、更早转型
  - 在斗争中斗倒老派
  - 绕过知识分子，或者用别的方式处理知识分子问题
- **好结局要多设计几个。** 比如文化大革命以某种形式真正实现了它宣称的目标，真正实现了某种民主，巴黎公社原则得到落实，没有被技术官僚夺舍，这些政策延续了下去。
- 好结局也要付代价，要回答三个问题。这件事历史上为什么没发生？谁付了代价？能维持多久？
- 完整清单见 `IF线与视觉设计.md` 第二节。

### 四、篇幅

- 每一幕不需要一样长。第二幕场景多、事件大，可以写得更长更细。
- 第二幕的安排是解放日报事件和一月风暴主要做铺垫，康平路和“上海人民公社”改名做成真正的选择节点。改名是巴黎公社 IF 线的入口。

### 五、写作分工

- 叙事正文由 Claude 直接写，用户来改。
- 正文要尽量有史料依据，依据交接说明第九节的文献清单。
- 写作偏好不变：不用破折号，不用冒号引出列表，不用“不是 X 而是 Y”句式。

### 六、受众

- 面向海内外华语读者。
- 词条要写得深，讲清楚“这个东西在当时意味着什么”。

### 七、视觉

- 不要全是文字。能加图片的地方都要加图片，或者用其他视觉效果。
- 方案见 `IF线与视觉设计.md` 第四节。要点是用 SVG 和 CSS 在页面里画出大字报、档案袋、地图、车票、电报、袖章、报纸头版复原等物件；历史照片用维基共享资源上的公有领域图片；每幕换一种纸张色调。
- 每张图也要有史料注，写明是历史照片、依据史料的复原还是游戏插画。

### 九、史实核查

- 写新内容之前先核查史实。第一轮结果见 `史实核查_第一轮.md`。
- 第一轮发现 demo 有三处要改。
  1. 安亭列车早上 8 时 17 分停下，卧轨在中午前后，demo 写成凌晨和“天还黑着”，要改。
  2. 张春桥是 11 日深夜在安亭谈判，13 日在文化广场签五项要求，demo 把两件事合成了“13 日夜安亭办公室”，要拆开。
  3. 据 RFA 的叙述，谈判时主要是潘国平在说，王洪文在一旁抽烟不说话，和叶永烈“先退一步”的说法相反，两说都要进游戏。
