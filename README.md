# 梦与非梦

以王洪文为第一视角的中文文字冒险游戏，题材是 1966 至 1976 年的上海文革。

- `梦与非梦.html` 可直接在浏览器打开的游戏文件，共六幕和一个尾声，从 1966 年安亭到 1992 年秦城
- `docs/讨论记录.md` 已定下的决定，和交接说明冲突时以此为准
- `docs/交接说明.md` 设计原则、写作风格、文献清单
- `docs/交接_第二阶段.md` 第二阶段的过程和成品，接手先读这个
- `.claude/skills/meng-yu-feimeng/SKILL.md` 写作、史料、版权、提交、引擎和测试的规矩
- `tests/` Playwright 测试脚本，用法见其中的 README
- `docs/史实核查_第一轮.md`、`docs/史实核查_第二轮.md`、`docs/史实核查_第三轮.md` 史实核查记录，第三轮是第一次读到原文
- `docs/IF线与视觉设计.md` IF 线、死局与视觉方案草案
- `docs/第二幕设计.md` 第二幕场景、事实标记、死局与 IF 种子
- `docs/全剧规划.md` 全剧结构、IF 线分布、进度
- `docs/待确认.md` 需要作者拍板的问题
- `sources/` 可公开的史料原文，受版权保护的书不放这里
